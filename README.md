# Tic Tac Toe Game 🎮

A simple web-based **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. This game features a classic two-player mode, win detection, draw handling, a congratulatory message display, and a reset function to start a new game instantly.

## ✨ Features

- **Two-Player Mode** (Player vs Player)
- **Turn-Based Play** (Starts with O, alternates between O and X)
- **Win Detection** using predefined winning patterns
- **Draw Detection** if all cells are filled with no winner
- **Visual Win Message** (text and optional GIF/image display)
- **Box Highlighting** on win (winning 3 boxes change background color)
- **Reset Button** to restart the game cleanly
- **Dynamic Subtitle** showing turn progression and game state

## 🛠 Technologies Used

- **HTML** for layout
- **CSS** for styling (including colors and basic layout)
- **JavaScript** for game logic and interactivity

## 🚀 How to Run

1. Clone or download the project files.
2. Open the `index.html` file in any web browser.
3. Click on boxes to play the game (O starts first).
4. Use the **Reset** button to start a new game anytime.
